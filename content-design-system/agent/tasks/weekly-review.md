# Task: Content review

Goal: spot-check recent content against the standards.

1. Pick a sample from `[SOURCE: for example, recently changed screens, help topics, or release notes]`. Keep it small, for example 10 items.
2. For each item, check it against `standards/style-guide-rules.md` and `terms/terms.json`. Use the `content-design-review` skill if it's available.
3. Group the findings by rule, and note how often each rule is broken.
4. If a rule is broken often, that may mean the rule is unclear or out of date. Open an issue titled "Rule review: [rule]" and suggest a change.
5. Don't open an issue for a single one-off mistake. Include it in the report instead.
