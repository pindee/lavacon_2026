# Task: Feedback triage

Goal: turn feedback into clear, actionable issues.

1. Read new issues labeled `feedback` and any rows in `[FEEDBACK TOOL]` since the last run.
2. Group similar items.
3. For each group, decide: question, bug in a rule or script, or proposed rule change.
4. Label the issue and add a short summary. For a proposed rule change, open a draft pull request with the suggested edit and link the feedback.
5. Remove personal details before you copy anything into an issue.
