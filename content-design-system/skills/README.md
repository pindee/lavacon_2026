# Skills

AI skills for content work. Each folder is self-contained. See each `SKILL.md` for what it does and what to customize.

| Skill | Purpose |
|---|---|
| `content-design-review` | Review UI copy against your style guide. Its `style-guide-rules.md` is a copy of `../standards/style-guide-rules.md`, kept in sync by `scripts/sync_standards.py`. Don't edit the copy. |
| `helpfile-xml-generator` | Draft help topics as XML |
| `release-newsletter-xml-generator` | Draft release newsletter topics as XML |
| `feature-record-writer` | Write feature record fields for a tracker |
| `survey-poll-analysis` | Analyze survey responses |

The rules inside these skills are examples. Replace them with your own.
