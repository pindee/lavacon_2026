# The Kevin Chili Test

Before you build an agent, ask: should this even be an agent or a skill? Does this process need automation?

The test is named after a famous office chili: made every year, with a recipe refined over time, and with a lot of careful prep the night before. If an AI agent could make chili, that recipe would be a great candidate for automation. The lesson isn't about chili. It's about the kind of problem that makes a good agent.

## The four questions

| Question | Yes looks like | No looks like |
|---|---|---|
| **Repetitive?** | You do it every week, month, or year | It's a one-off |
| **Rule-based?** | There are defined steps and instructions | It depends on gut feel |
| **Time-consuming?** | It eats real hours, or prep the night before | It takes five minutes |
| **Predictable?** | The same process gives the same result | Every run is different |

Four yeses make a strong candidate.

## Red flags

If any of these is true, you probably don't need automation yet. You need a better process first.

- The process is different every time
- It relies heavily on human judgment
- Nobody can explain how it works

## Agent, skill, or neither?

1. **Can someone explain the steps?** If not, fix the process first.
2. **Is it the same each time?** If not, fix the process first.
3. **Does it score four yeses?** If not, automation may not pay off.
4. **Skill or agent?**
   - A **skill** handles a task inside a conversation, loaded on demand.
   - An **agent** has its own fixed instructions and is used on its own, runs on a schedule, or serves many people.
5. **What stays human?** Name the handoffs before you build. Tasting is still a person's job.

## Scoring examples

| Process | Repetitive | Rule-based | Time-consuming | Predictable | Result |
|---|---|---|---|---|---|
| Yearly chili | Yes | Yes | Yes | Yes | Strong candidate |
| Writing feature record text | Yes | Yes | Yes | Mostly | Good candidate. Agent, because of the strict format and wide audience |
| Weekly check that tools match the standards | Yes | Yes | Yes | Yes | Good candidate. Agent, because it runs on a schedule |
| Deciding the brand voice | No | No | Sometimes | No | Not yet. It needs human judgment |
| "We just kind of do it" | ? | No | ? | No | Fix the process first |
